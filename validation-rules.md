# Validation Rules

Use these checks when validating files in this project:

1. **Path and naming:** Confirm the file is stored in the expected directory and follows the repository's naming convention.
2. **Required structure:** Verify that required headings, sections, fields, or code symbols are present and in the expected order.
3. **Content completeness:** Check that required values are populated and that no placeholder text, truncated content, or accidental TODOs remain.
4. **Formatting:** Confirm the file uses the project’s established formatting, indentation, line endings, and Markdown syntax where applicable.
5. **References:** Verify that links, imports, file paths, and referenced identifiers resolve to existing targets.
6. **Validation tools:** Run the smallest applicable parser, linter, type checker, or test suite and confirm it completes without errors.
