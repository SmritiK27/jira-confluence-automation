# Weekly Status Report Instructions

- Use Markdown format.
- Include only these sections: Accomplishments, Blockers, Next Week.
- Write each section as a Markdown heading followed by bullet points.
- Use bullet points only; do not add paragraphs or narrative text.
- Keep the report to 20 lines or fewer.
- Use a professional tone.
- Remove fluff words, filler, and informal language.

## Accomplishments
- Summarize completed work with clear outcomes.

## Blockers
- List issues that are delaying progress or require action.

## Next Week
- State planned work in concrete, prioritized items.
